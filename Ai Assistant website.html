Three passes over every file

From a messy shared drive to a searchable memory.

PASS 01 — INGEST

Read and split

Files are parsed with layout intact — tables stay tables, slide notes stay attached to their slide — then split at semantic boundaries, not fixed character counts.

PASS 02 — LINK

Connect the pieces

Policy numbers, project codes and people are resolved across documents, so a lease clause and the office it describes end up on the same node.

PASS 03 — ANSWER

Retrieve and cite

A question pulls the passages that actually support the answer. If the library doesn't contain it, Atlas says so instead of guessing.
